## 🔧 Methods

In Java, a **method** is a block of reusable code that performs a specific task. They are essential for following the **DRY (Don't Repeat Yourself)** principle, allowing you to write code once and execute it whenever needed by calling it.

```java
static void happyBirthday(String name, int age){
    System.out.println("Happy birthday to you!");
    System.out.printf("Happy birthday dear %s!\n", name);
    System.out.printf("You are %d years old!!\n", age);
    System.out.println("Happy birthday to you!\n");
}
```
See: src/w03/methods/MethodsDemo.java

Key concepts regarding methods include:
* **Declaration:** Methods are defined with a return type (or void if they return nothing), a descriptive name, and parentheses for parameters.
* **Parameters and Arguments:** You can pass data into a method by defining parameters in the method signature and providing arguments when calling it. The number, order, and data type of arguments must match the parameters.
* **Return Values:** Using the return keyword, a method can send a value back to the place where it was called.

```java
static boolean ageCheck(int age){
    if(age >= 18){
        return true;
    }
    else {
        return false;
    }
}
```
See: src/w03/methods/MethodsDemo.java

```java
int age = 17;
if (ageCheck(age)){
    System.out.println("You may sign up!!");
}
else {
    System.out.println("You must be 18+ to sign up!");
}
```

## 🔁 Overloaded Methods

* **Overloaded Methods:** You can have multiple methods with the same name as long as they have different parameter lists (unique signatures). This allows methods to handle different types or quantities of inputs.

```java
static double add(double a, double b){
    return a + b;
}

static double add(double a, double b, double c){
    return a + b + c;
}
```
See: src/w03/methods/OverloadedMethodsDemo.java

```java
static String bakePizza(String bread){
    return bread + " Pizza";
}

static String bakePizza(String bread, String cheese){
    return cheese + " " + bread + " Pizza";
}
```
See: src/w03/methods/OverloadedMethodsDemo.java

## 🎯 Variable Scope

* **Variable Scope:** Variables declared inside a method have **local scope**, meaning they are only accessible within that specific method's curly braces.

```java
public class VariableScopeDemo {

    static int x = 1; // CLASS

    public static void main(String[] args) {
        int x = 2; // LOCAL
        System.out.println(x);
        doSomething();
    }

    static void doSomething(){
        int x = 3; // LOCAL
        System.out.println(x);
    }
}
```

## 🧩 Interfaces

In Java, an **interface** serves as a **blueprint for a class**. It defines a set of abstract methods that any class implementing the interface must provide, effectively acting as a contract.

```java
public interface Prey {
    void flee();
}
```
See: src/w03/interfaces/Prey.java

```java
public interface Predator {
    void hunt();
}
```
See: src/w03/interfaces/Predator.java

Key characteristics of interfaces include:

* **Multiple Inheritance-like Behavior:** Unlike standard class inheritance where a child can only have one parent, a class can implement **multiple interfaces**. This allows for more flexible object design.

```java
public class Fish implements Predator, Prey{

    @Override
    public void flee(){
        System.out.println("** The fish is swimming away!! **");
    }

    @Override
    public void hunt(){
        System.out.println("** The fish is hunting!!! **");
    }
}
```
See: src/w03/interfaces/Fish.java

* **Defining Capabilities:** Interfaces are ideal for defining common behaviors (like Prey or Predator capabilities) that different classes can share, even if they aren't directly related in a hierarchy.
* **Implementation Requirement:** When a class implements an interface, it must finish defining the abstract methods declared within that interface, typically using the @Override annotation.

```java
public class Rabbit implements Prey{

    @Override
    public void flee(){
        System.out.println("** The rabbit is running away!! **");
    }
}
```
See: src/w03/interfaces/Rabbit.java

* **Polymorphism:** Interfaces can be used to achieve polymorphism, allowing objects of different classes to be treated as types of that interface.

```java
Rabbit rabbit = new Rabbit();
Hawk hawk = new Hawk();
Fish fish = new Fish();

hawk.hunt();
rabbit.flee();
fish.flee();
fish.hunt();
```
See: src/w03/interfaces/InterfacesDemo.java

## 🧬 Generics

In Java, **generics** allow you to write code—such as classes, interfaces, or methods—that is **compatible with multiple data types** while maintaining type safety. Instead of restricting a container to a single type (like just `String` or `Integer`), you can create reusable components that adapt to whatever type you specify when you use them.

Key concepts of generics include:

* **Type Parameters:** Represented by a letter inside angle brackets (e.g., `<T>`), these act as **placeholders** for a data type that will be defined later.
* **Type Arguments:** These are the actual types you pass in when creating an instance of a generic class or calling a method (e.g., `Box<String>`), replacing the placeholder.
* **Reusability:** By using generics, you avoid creating separate, nearly identical classes for different data types. For example, a single `Box<T>` class can store a `String`, an `Integer`, or any other object type.
* **Multiple Types:** You can use more than one type parameter if needed, often following the convention `T`, `U`, `V`.

```java
public class Box<T> {

    T item;

    public void setItem(T item){
        this.item = item;
    }

    public T getItem(){
        return this.item;
    }

}
```

## 📦 Array

In Java, an **array** is a fixed-size data structure used to store multiple values of the same data type in a single variable; elements are accessed by index, starting from 0.

Key concepts regarding arrays include:

* **Reference Data Type:** Accessing the array name directly returns a memory address, not the values themselves.
* **Fixed Size:** Once created, an array's length cannot be changed.

```java
String[] fruits = {"Apple","Orange","Banana","Coconut"};
// fruits[0] = "Pineapple";
int numOfFruits = fruits.length;

System.out.println(fruits[3]);
System.out.println(numOfFruits);
```
See: src/w03/arraylist/ArrayListDemo.java

* **Utility Methods:** `java.util.Arrays` provides `sort()` for ordering elements and `fill()` for populating the array with specific values.

```java
Arrays.sort(fruits);
Arrays.fill(fruits, "Pineapple");
```
See: src/w03/arraylist/ArrayListDemo.java

* **Iteration:** Arrays can be traversed with a standard for loop or an enhanced for-each loop.

```java
for (int i = 0; i < fruits.length; i++) {
    System.out.println(fruits[i]);
}

for(String fruit: fruits){
    System.out.println(fruit);
}
```
See: src/w03/arraylist/ArrayListDemo.java

## 🧮 Varargs

In Java, **varargs** allow a method to accept a variable number of arguments of the same type.

Key concepts regarding varargs include:

* **Flexibility:** One method can handle any number of arguments instead of writing multiple overloaded methods.
* **Syntax:** The ellipsis (`...`) after a data type in a method parameter tells the compiler to pack the passed arguments into an array.
* **Implementation:** Inside the method, the parameter behaves like a normal array and can be iterated with a for-each loop.
* **Example signature:** `public static int add(int... numbers)` — callable as `add(1, 2, 3)` or `add(1, 2, 3, 4, 5)`.

```java
static int add(int... numbers){
    int sum = 0;
    for (int i = 0; i < numbers.length; i++) {
        sum += numbers[i];
    }
    return sum;
}
```

## 🗺️ HashMap

In Java, a **HashMap** is a highly efficient data structure used to store data in **key-value pairs**, associating a unique key with a specific value for fast lookup.

Key concepts regarding HashMaps include:

* **Uniqueness:** Each key must be unique; adding a duplicate key overwrites the previous value associated with that key.
* **Performance:** A HashMap does not maintain a specific order, but is extremely fast and memory-efficient for data retrieval.
* **Type Parameters:** You must specify data types for both key and value (e.g. `HashMap<String, Double>`), which must be reference data types.

```java
HashMap<String, Double> map = new HashMap<>();

map.put("apple", 0.50);
map.put("orange", 0.75);
map.put("banana", 0.25);
map.put("coconut", 1.50);
```
See: src/w03/hashmap/HashMapDemo.java

* **Common Methods:**
  * `put(key, value)`: adds an entry to the map
  * `get(key)`: retrieves the value associated with a specific key
  * `remove(key)`: deletes an entry
  * `containsKey(key)`: checks if a specific key exists in the map
  * `size()`: returns the number of entries in the map

```java
// map.remove("apple");
// System.out.println(map.get("apple"));
// System.out.println(map.containsKey("coconut"));
// System.out.println(map.containsValue(1.50));
// System.out.println(map.size());
```
