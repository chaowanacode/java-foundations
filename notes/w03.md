## 🔧 Methods

In Java, a **method** is a block of reusable code that performs a specific task. They are essential for following the **DRY (Don't Repeat Yourself)** principle, allowing you to write code once and execute it whenever needed by calling it.

```java
static void happyBirthday(String name, int age){
    System.out.println("Happy birthday to you!");
    System.out.printf("Happy birthday dear %s!\n", name);
    System.out.printf("You are %d years old!!\n", age);
    System.out.println("Happy birthday to you!\n");
}
```
See: src/w03/methods/MethodsDemo.java

Key concepts regarding methods include:
* **Declaration:** Methods are defined with a return type (or void if they return nothing), a descriptive name, and parentheses for parameters.
* **Parameters and Arguments:** You can pass data into a method by defining parameters in the method signature and providing arguments when calling it. The number, order, and data type of arguments must match the parameters.
* **Return Values:** Using the return keyword, a method can send a value back to the place where it was called.

```java
static boolean ageCheck(int age){
    if(age >= 18){
        return true;
    }
    else {
        return false;
    }
}
```
See: src/w03/methods/MethodsDemo.java

```java
int age = 17;
if (ageCheck(age)){
    System.out.println("You may sign up!!");
}
else {
    System.out.println("You must be 18+ to sign up!");
}
```

## 🔁 Overloaded Methods

* **Overloaded Methods:** You can have multiple methods with the same name as long as they have different parameter lists (unique signatures). This allows methods to handle different types or quantities of inputs.

```java
static double add(double a, double b){
    return a + b;
}

static double add(double a, double b, double c){
    return a + b + c;
}
```
See: src/w03/methods/OverloadedMethodsDemo.java

```java
static String bakePizza(String bread){
    return bread + " Pizza";
}

static String bakePizza(String bread, String cheese){
    return cheese + " " + bread + " Pizza";
}
```
See: src/w03/methods/OverloadedMethodsDemo.java

## 🎯 Variable Scope

* **Variable Scope:** Variables declared inside a method have **local scope**, meaning they are only accessible within that specific method's curly braces.

```java
public class VariableScopeDemo {

    static int x = 1; // CLASS

    public static void main(String[] args) {
        int x = 2; // LOCAL
        System.out.println(x);
        doSomething();
    }

    static void doSomething(){
        int x = 3; // LOCAL
        System.out.println(x);
    }
}
```
See: src/w03/methods/VariableScopeDemo.java
